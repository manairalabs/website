# Manaira Labs Website

Official website for [Manaira Labs](https://manairalabs.com) - AI Products & Solutions for Business.

Built with [Astro](https://astro.build/).

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:4321

## Documentation

- [Development Guide](docs/development.md) - Setup, build, and deployment instructions

## Features

- Static site generation with Astro
- Blog with Markdown content
- Light/dark theme support
- SEO optimized (sitemap, Open Graph, Twitter Cards)
- Automatic deployment to GitHub Pages
